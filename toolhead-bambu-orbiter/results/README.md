# Results

Raw numbers behind the figures:
- `cfd/*.json`: CFD metrics per case (`base` = stock, `a10F` = final; `_free` = no bed).
- `fea/<run>/`: modes, frequency responses and energy split per run (`h_base_ASA` = stock, `f_s12_ASA` / `f_s12_ASACF` = final).
- `figures_data.json`: the values plotted in the figures.
